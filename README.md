## Start in 30 minutes
1. Copy `templates/agent-design-canvas.md`.
2. Use `examples/fictional-inbox.csv` rather than real customer information.
3. Run the prompt in `prompts/inbox-draft-only.md`.
4. Check every result against the fictional record and the expected behavior in `docs/test-cases.md`.
5. Do not connect live inboxes or allow external sends during this experiment.
